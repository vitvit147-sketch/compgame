# Party Games Hub 🕵️‍♂️🎭💣

Веб-приложение для игр в компании друзей со смартфонов.

## Включенные игры:
1. **🕵️‍♂️ Шпион (Spyfall) — Pass & Play на 1 телефоне**:
   - Игра без интернета и VPN на одном общем смартфоне.
   - 40+ локаций, 6 категорий, профессии для каждого игрока.
   - Таймер расследования со звуковыми эффектами и шпаргалкой локаций.

2. **🎭 Мафия — Пульт ведущего**:
   - Автоматический расчет ночных действий (Доктор, Путана, Маньяк, Комиссар и др.).
   - Дневной таймер с речью игроков, счетчик фолов и голосование (суд).

3. **💣 Слова-мины (Trapwords) — Онлайн со смартфонов**:
   - Комнаты по 4-значным кодам для игры со своих телефонов.
   - Скрытые слова-ловушки и кнопка «БАХ!».

## Стек:
- React 19 + Vite 8
- Tailwind CSS v4
- Lucide React
- Socket.io (для онлайн-режима)
